# 🧩 Sudoku Game

A modern Sudoku game built with **HTML**, **CSS**, and **JavaScript**. It features multiple difficulty levels, a clean responsive interface, a game timer, and local high-score saving.

## 🌐 Live Demo

**Play Now:** https://fady-albert.github.io/SUDOKU/

---

## ✨ Features

*  Interactive Sudoku gameplay
*  Three difficulty levels

  * Easy
  * Medium
  * Hard
*  Real-time game timer
*  Saves your best completion time using Local Storage
*  Modern UI
*  Dark-themed design
*  Fast and lightweight (No frameworks)

---

## 🛠️ Built With

* HTML5
* CSS3
* Vanilla JavaScript

---

## 🎯 How to Play

1. Open the game.
2. Choose a difficulty level.
3. Fill the empty cells with numbers from **1–9**.
4. Follow the Sudoku rules:

   * Every row must contain each number exactly once.
   * Every column must contain each number exactly once.
   * Every 3×3 box must contain each number exactly once.
5. Complete the board to win.
6. Try to beat your best time!
